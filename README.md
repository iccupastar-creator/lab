# Бланк Качества: Яблочное Пюре (ГОСТ 32742-2014)

Лабораторное приложение для формирования официальных бланков/паспортов физико-химического анализа натурального яблочного пюре.

## Возможности
- **3 обязательных показателя**:
  1. Массовая доля сухих веществ (Brix), %
  2. Титруемая кислотность (по яблочной кислоте), %
  3. Активная кислотность (pH)
- **Опциональные поля**: Номер партии, Лаборант / Исполнитель.
- **Экспорт в JPG**: Отрисовка в высоком разрешении (2x Retina Canvas) и сохранение в галерею телефона.
- **Экспорт в Word (.docx)**: Автономная генерация документа Word с таблицей и нормами ГОСТ без интернета.
- **Поделиться**: Отправка в Telegram, WhatsApp и любые другие мессенджеры.
- **Копирование**: Копирование готового бланка в буфер обмена.
- **Журнал анализов**: Локальное сохранение истории анализов и экспорт в CSV.
- **Адаптивный дизайн**: Высокая контрастность, крупные шрифты, поддержка телефонов и ПК.
- **Полное отсутствие эмодзи**: Все элементы построены на векторных SVG.

## Запуск и использование
1. **Онлайн версия**: Открыть в браузере мобильного или ПК.
2. **Windows ПК**: Запустить файл `PureeBlank.exe` из папки `dist/`.
3. **Android APK**: Автосборка через GitHub Actions (`.github/workflows/build-apk.yml`).
